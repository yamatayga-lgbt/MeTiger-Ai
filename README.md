# MeTiger Ai 🐯

<img src="docs/agent-avatar.png" width="110" alt="MeTiger Ai" />

**Универсальный ИИ-агент в Telegram Mini App.**

Минималистичный интерфейс в духе Claude / Grok / Linear: тёмная и светлая темы,
один универсальный агент, инструменты и командная палитра — всё в одном мини-приложении.

> 📦 **Статус:** v0.2.0 — к UI подключён **движок** (Этап 1 переноса из Yama AI):
> обход бесплатных провайдеров с ротацией ключей, квотами и паузами под тариф,
> классификатор задачи, `POST /api/chat` на Pages Functions. Прогон кода, память,
> бот и админка — следующие этапы (см. `ПЕРЕНОС.md`).

## 🚀 Быстрый старт

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшен-сборка в dist/
```

## 🔌 Движок локально

```bash
cp .dev.vars.example .dev.vars   # ключи бесплатных провайдеров (в git не попадает)
npm run api                      # http://127.0.0.1:8788/api/chat
npm run dev                      # фронт на 5173, /api проксируется на движок
npm test                         # 62 офлайн-проверки движка, сети не требуют
```

## 🧠 Совет голов

На задачах, где есть верный ответ (арифметика, логика, «сколько осталось»), ответ
перепроверяют независимые головы с других бесплатных провайдеров, а факт с картинки —
зрячие головы. Результат видно в ответе, а не в догадках: «сошлись 3/3»,
«подтверждаю», «Головы не сошлись (…) — число спорное» или «пропущено: <причина>».
Ничего не выдаётся за проверенное, если проверки не было. Выключается переменными
`ENSEMBLE=0` и `VCOUNCIL=0`, настройки — в `ПЕРЕНОС.md`.

Вердикт виден прямо в чате — тонкой подписью под ответом (кто отвечал, за сколько и
что сказал совет). Картинки прикрепляются в чате (до двух, сжимаются до 1024 px) и
уходят в движок — именно так совет зрячих голов становится доступен не только через API.

## 🗺 Структура

```
src/
├── components/      # Sidebar, Topbar, BottomNav, CommandPalette, UI-примитивы
├── views/           # Chat, Agent, Tools, Settings
├── hooks/useTheme.ts
├── lib/
│   ├── telegram.ts  # Telegram WebApp SDK + fallback
│   └── mock.ts      # демо-данные агента, инструментов, ответов
└── styles/index.css # дизайн-система (токены, темы, компоненты)

engine/              # сам движок: провайдеры, роутинг, форма запроса, советы голов
├── providers.js     # таблица бесплатных провайдеров и их моделей
├── route.js         # классификатор задачи и порядок моделей внутри провайдера
├── shape.js         # тело запроса и разбор ответа — формат каждого провайдера
├── chat.js          # обход очереди, ключи, дедлайны, врезка советов
├── ensemble.js      # голоса на задачах с верным ответом
└── vcouncil.js      # совет зрячих голов на фактах по картинке
functions/api/chat.js # вход в движок: POST /api/chat (Pages Function)
scripts/api-dev.js    # тот же вход в Node: npm run api
src/lib/api.ts        # клиент фронта: sendChat + подпись «кто отвечал и что сказал совет»
src/lib/images.ts     # вложения: ≤2 картинки, сжатие до 1024 px перед отправкой
test/                 # офлайн-проверки движка (сети нет): route, chat, council
workers/stats/        # Durable Object: счётчики
```

## 🎨 Дизайн-система

- **Тёмная тема** — тёмный графит + тёплый «тигровый» акцент `#F5A623`
- **Светлая тема** — тёплая бумажная база, вдохновлённая Claude
- Одна типографика (системный стек), тонкие границы, мягкие тени
- Анимации появления, тактильная отдача (HapticFeedback), `⌘K` — командная палитра

## 🤖 Telegram Mini App

Приложение работает как Web App бота [@Metigerai_bot](https://t.me/Metigerai_bot):

- автоматически подхватывает имя и аватар пользователя
- следует теме Telegram / системной теме
- кнопка меню бота открывает мини-приложение
- вне Telegram работает в демо-режиме

## ☁️ Деплой (Cloudflare Pages)

Хостинг — **Cloudflare Pages** (бесплатно, edge-CDN, автоматический деплой).

- Прод: `https://metiger-ai.pages.dev`
- Каждый push в `main` собирает и публикует приложение
- GitHub Actions (`ci.yml`) дополнительно проверяет сборку на каждый push

В будущем бэкенд (агенты, API-ключи, админка) — на Cloudflare Workers, бесплатно до 100k запросов/день.
