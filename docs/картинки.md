# Картинки: откуда берутся и почему иногда текстом

Короткая справка про генерацию изображений. Для тех, кто чинит, и для тех, кто
задаёт вопросы «почему не нарисовалось».

## Цепочка источников

`engine/imggen.js`, `createImggen()`. Порядок: **gemini → odirouter → pollinations**.
Первый ответивший выигрывает, остальные не трогаются.

| Источник | Что умеет | Чем живёт |
|---|---|---|
| gemini | рисует и **правит** присланную картинку | `GEMINI_KEYS` |
| odirouter | рисует и правит | `ODIROUTER_KEYS` |
| pollinations | только рисует (правка не умеет) | без ключа |

Отказавший источник **паркуется** на `IMGGEN_RETRY_MS` (по умолчанию 5 минут),
чтобы не пинать мёртвый API каждым запросом. Отдельно от этого: ответ **402/429** —
это не поломка, а кончившийся бесплатный лимит, и он паркуется только на
`IMGGEN_BUSY_MS` (по умолчанию **минута**). Разные причины — разное ожидание.

## Правило Pollinations, о которое легко споткнуться (замерено 6 окт 2026)

Бесплатен **только голый адрес**:

```
https://image.pollinations.ai/prompt/<текст-промпта>
```

Любой параметр — `width`, `height`, `nologo`, `model`, `seed` (каждый проверен по
отдельности) — отвечает **402 Payment Required** с пустым телом `{}`. Прежний адрес
был с `width/height/nologo`, то есть каждый заказ картинки упирался в 402, и человек
получал текст вместо картинки.

Поэтому слой делает так: сначала **голый** адрес, при неудаче — прежний с
параметрами (вдруг платный шлюз снимут), а удачную форму **запоминает** на изолят и
больше не тратит лишних запросов. Плата за это — картинка в размере по умолчанию,
а не в заказанном: `size` у Pollinations сейчас не работает в принципе.

Если 402 пришёл и на голый адрес — это лимит, и в причине так и написано:
«бесплатный лимит Pollinations исчерпан». Через минуту слой вернётся к нему сам.

## Живость источников

`img:alive` в общем KV (`env.MEMORY`): отметка времени «этот источник уже отвечал».
Живёт 24 часа (`IMGGEN_ALIVE_MS`), запись — не чаще раза в 60 с. Благодаря ей
`GET /api/chat` показывает не вечное «не проверен», а «pollinations · жив · только
что». Хранится только время — ни промптов, ни картинок.

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `IMGGEN` | — | `off` — слой выключен целиком |
| `IMGGEN_SOURCE` | — | оставить только один источник (для отладки) |
| `IMGGEN_TIMEOUT_MS` | 90000 | потолок на один источник |
| `IMGGEN_RETRY_MS` | 300000 | парковка сломавшегося источника |
| `IMGGEN_BUSY_MS` | 60000 | парковка источника, упёршегося в лимит |
| `IMGGEN_POLLINATIONS` | — | `off` — не использовать Pollinations |
| `IMGGEN_POLL_MODEL` | — | модель в адресе (учтите: это параметр ⇒ 402) |
| `IMGGEN_ALIVE_MS` | 24 ч | сколько считается «источник жив» |

## Чем проверять

```bash
# быстро: только Pollinations, вживую, без сети Cloudflare
node --input-type=module -e "
import { createImggen } from './engine/imggen.js';
const img = createImggen({ env: { IMGGEN_SOURCE: 'pollinations' } });
const r = await img.generate({ prompt: 'рыжий кот в снегу' });
console.log(r.ok ? r.source + ' ' + Math.round(r.bytes.length/1024) + ' КБ' : r.why);
"

node test/imggen.test.js     # 74 проверки, секции до J включительно
```

Тесты: секция **I** — формы адреса Pollinations, секция **J** — лимит против поломки,
секция **H** — живость в KV.
