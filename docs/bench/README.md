# MeTiger Bench

Набор проверяемых вопросов, чтобы улучшать MeTiger по цифрам, а не на глаз.

- Вопросы: `bench/questions.mjs` — 73 штуки в 7 категориях (математика, логика, факты, инструкции,
  русский язык, код, сложное). Ответ сверяется машиной: число/факт с эталоном, формат — кодом,
  **код из ответа запускается в node и прогоняется тестами**.
- Прогон: `node scripts/bench.mjs` (MeTiger и DeepSeek), `--only metiger`, `--cat сложное`,
  `--par 2`, `--gap 6200` (сайт пускает 12 запросов в минуту с адреса).
- Перепроверка без запросов: `node scripts/bench.mjs --redo файл.json --offline` (ответы хранятся в json).
- Ответ, где модель путается на глазах у человека («подожди, пересчитаем…»), не засчитывается.

## DeepSeek для сравнения

Своего ключа DeepSeek у проекта нет: «deepseek» — это тот же сайт с закреплённой моделью
`odirouter · deepseek-v4-flash` и простым system без навыков и советов. Бесплатная квота odirouter
маленькая: при прогоне DeepSeek отвечает «ни один провайдер не ответил» (429) — такие случаи в отчёте
отдельной строкой «сбой доступа», а не ошибкой модели.

## Прогоны

| Дата | Версия | MeTiger | DeepSeek | Заметки |
|---|---|---|---|---|
| 2026-10-09 | 0.131 | 53/54 базовых (98%), 18/19 сложных (95%) — **71/73** | 28/54, из них 26 — сбой доступа; на 28 отвеченных 28/28 | ничья по точности там, где DeepSeek ответил; MeTiger быстрее (2,2 с против 3,7 с) и отвечает всегда |

Ошибки MeTiger в 0.131 → что сделано в 0.132:
- **h5** «Сколько букв „р“ в „пререкаться“?» — «3… подожди, пересчитаем» → инструмент `letters` (считает код).
- **i7** «предложение ровно из 5 слов» → 4 слова → самопроверка `exactCountIssue` пересчитывает и чинит.
