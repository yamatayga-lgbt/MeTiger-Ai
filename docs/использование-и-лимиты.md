# Использование и Лимиты (0.081–0.083)

Экран с живым счётом расхода провайдеров. Открывается двумя путями: пункт
**«Использование и Лимиты»** в разделax сайдбара (первым, над «Настройками») и действие
в палитре команд (`⌘K`). В Настройках его намеренно **нет**: с 0.083 строка оттуда убрана,
потому что дублировала тот же переход — человек искал расход в двух местах вместо одного.

**Где живёт код**

| Файл | Что делает |
|---|---|
| `engine/usage.js` | счётчик: `attempt` / `outcome` / `pause`, срез, запись в KV с паузой |
| `engine/chat.js` | три точки врезки: `attemptOne` → `attempt`, `note` → `outcome`, `punish` → `pause` |
| `functions/api/usage.js` | `GET /api/usage` — то же, что видно на экране, одним curl |
| `functions/api/chat.js` | `engine.usageFlush()` в `after()` (через `waitUntil`, человек записи не ждёт) |
| `src/views/UsageView.tsx` | экран |
| `src/lib/usage.ts` | опрос: раз в 5 с, только пока экран открыт и вкладка видима |
| `src/lib/models.ts` | `telemetrySummary()` — счёт **этого устройства** (localStorage) |
| `test/usage.test.js` | 42 проверки, подключён в `npm test` |

**Как считается (и почему так)**

- Считается **каждая исходящая попытка**: таймаут, 429 и мёртвый ключ — тоже расход
  квоты провайдера, а не «провайдер молчит».
- **Сутки — по UTC**, как у провайдеров. Сброс в 00:00 UTC (03:00 по Минску); на экране
  виден таймер до сброса, чтобы «счётчик обнулился ночью» не выглядело поломкой.
- Изоляты Cloudflare складывают свои числа в KV **read-modify-write** не чаще
  `USAGE_WRITE_MS` (30 с), поэтому `USAGE_WRITE_MAX` (300 записей на изолят за сутки)
  защищает общий бюджет KV (1000 записей в сутки на бесплатном тарифе). Если хранилище
  отказало — пачка **не теряется**, а уезжает следующей записью.
- Точность подписана на экране честно: «в день» — сложение изолятов, «в минуту» —
  нижняя оценка (атомарного счётчика в KV нет). Рядом стоит счёт **этого устройства** —
  мгновенный и точный, но про одного человека; в одно число они не смешиваются.

**Переменные**

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `USAGE` | включён | `0` — выключить слой (счёт останется в памяти изолята) |
| `USAGE_WRITE_MS` | `30000` | пауза между записями в KV (пол 10000) |
| `USAGE_READ_MS` | `15000` | сколько держать прочитанный срез |
| `USAGE_WRITE_MAX` | `300` | потолок записей на изолят за сутки |
| `USAGE_RPM` | справочные | потолки «в минуту» строкой JSON: `{"groq":30}` |

**Проверка**

```bash
curl -s https://metiger-ai.pages.dev/api/usage | head -c 600
# повторяемость локально: npm run api (8788) + npm run dev (5173, сам проксирует /api)
node test/usage.test.js
```

Живой ответ прода (6 октября 2026, после выкладки): `kv: true`, `writeCap: 300`,
`rate: 12 запросов / 60 с`, 12 провайдеров в списке, расход считается по каждому
(у кого нет ключа — строка есть, но помечена «нет ключа»).

**Что уже сделано в этой линии (0.080–0.082)** — чтобы не делать дважды:

- `0.082` — потолок записей в KV (`USAGE_WRITE_MAX`) виден в строке «Точность».
