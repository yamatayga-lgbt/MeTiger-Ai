# Бесплатные модели и провайдеры: кандидаты для MeTiger Ai

Проверка: **18 октября 2026**. Каталоги бесплатных моделей меняются быстро,
поэтому перед включением каждого имени нужен живой smoke именно тем ключом,
который будет лежать на проде.

## Что уже есть

В `engine/providers.js` уже 12 провайдеров: Gemini, Groq, Mistral,
OpenRouter, Cloudflare Workers AI, Xkiro, Z.AI, Atria, LLM7, Kilo,
ShareLLM и OdiRouter. Живой `/api/models` на момент проверки показывал
91 модель на витрине и 226 имён в каталоге.

Важная деталь: часть новых имён уже видна в каталоге через Xkiro, Kilo и
OpenRouter, но **не входит в автоматические пулы** из `TABLE`. Их можно
выбрать/запинить, однако обычный авто-маршрут ими пока не пользуется.
Поэтому первый выигрыш — не обязательно новый провайдер: сначала стоит
прогнать бенч по уже доступным именам и поднять лучшие в пулы.

## Критерии отбора

1. Бесплатность возобновляемая, а не одноразовая проба.
2. Нет обязательной карты для первого эшелона.
3. OpenAI-совместимый API или понятный адаптер.
4. Модель даёт новое качество: русский язык, мультимодальность, код,
   длинный контекст, рассуждение или независимую квоту.
5. Условия не запрещают публичное использование. Trial/evaluation-only
   провайдеры вынесены отдельно и в прод без смены лицензии не идут.

### 7. OVHcloud AI Endpoints — ключ вообще не нужен

Endpoints у Zen разные по семействам (`chat/completions`, `responses`,

Ссылки: https://opencode.ai/docs/zen/,
https://opencode.ai/zen/v1/models

## Если получится зарегистрироваться: самые большие квоты

### GigaChat API — стратегически главная для обгона №1

Официальный Freemium для физлиц на 12 месяцев:

- Lite (`GigaChat`/`GigaChat-2`) — 250 млн токенов;
- Pro (`GigaChat-Pro`/`GigaChat-2-Pro`) — 40 млн;
- Max (`GigaChat-Max`/`GigaChat-2-Max`) — 25 млн;
- Ultra (`GigaChat-3-Ultra`) — 50 млн.

Итого 365 млн токенов. Но:

- нужен проект в Sber Studio и Authorization Key; access token живёт
  30 минут и получается OAuth-обменом;
- физлицам доступен один поток;
- Freemium-контент по официальным условиям — для личного некоммерческого
  использования; распространение/продажа требуют платного пакета. Для
  публичного MeTiger безопасная первая форма — **owner-only lane**, а не
  общий пул;
- endpoint требует корневой сертификат Минцифры. Из обычной среды
  `api.giga.chat` не проходит проверку стандартным CA-bundle. Первый
  технический тест после ключа — именно TLS из Cloudflare Worker; если не
  пройдёт, понадобится Custom Origin Trust Store или внешний прокси.

Ссылки: https://developers.sber.ru/docs/ru/gigachat/tariffs/individual-tariffs,
https://developers.sber.ru/docs/ru/gigachat/tariffs/commercial,
https://developers.sber.ru/docs/ru/gigachat/quickstart/ind-using-api,
https://developers.sber.ru/docs/ru/gigachat/certificates

## Какие ключи просить у владельца

### Первая очередь — без карты

1. `SENSENOVA_KEYS` — SenseNova global API key (`sk-...`).

## B. Новые провайдеры второго прохода

### Inception Labs — Mercury 2.5: 100 млн бесплатных токенов

- Каждый новый аккаунт: **100 млн токенов** без платёжных данных
  (разово; срок годности проверить в кабинете).
- Free-tier лимиты: 1 000 запросов/мин, 1 млн входных и 100 тыс.
  выходных токенов в минуту.
- Mercury 2.5 — диффузионная LLM: ~1 100 ток/с, контекст 260K, tools,
  JSON, регулируемое рассуждение; по заявлению Inception — уровень
  GPT-5.6 Luna / Gemini 3.5 Flash-Lite / Claude Haiku 4.5.
- API OpenAI-compatible: `https://api.inceptionlabs.ai/v1`.
- Env: `INCEPTION_KEYS`.
- Роль: быстрая голова для fast-очереди и черновиков советов.

Ссылки: https://docs.inceptionlabs.ai/get-started,
https://docs.inceptionlabs.ai/get-started/rate-limits,
https://www.inceptionlabs.ai/models

### Puter.js — «пользователь платит сам»

- Каждый пользователь входит своим аккаунтом Puter и тратит **свою**
  бесплатную месячную норму; разработчик не платит ничего.
- 500+ моделей: GPT-6.x, Claude, Gemini 3.8 Flash, Qwen, Solar Pro 4 и др.
- Не серверный ключ: это отдельная опция во фронтенде (кнопка «войти в
  Puter»), запросы идут из браузера. Размер бесплатной нормы не опубликован.
- Стратегическая ценность: честный путь к frontier-моделям для обгонов
  ChatGPT и Claude без наших денег. Минусы — внешний скрипт, логин в
  сторонний сервис, промпты уходят в Puter.

Ссылки: https://docs.puter.com/user-pays-model/,
https://developer.puter.com/tutorials/free-unlimited-ai-api/

### BlockRun — без ключа, но с подменой

- `https://blockrun.ai/v1`, бесплатные модели работают с пустым auth.
  Каталог: Nemotron 3 Ultra 550B, Nemotron 3.5 Lightning, Nemotron Nano Omni,
  Llama 3.2 11B Vision, North Mini Code, Laguna XS 2.1, Muse Glimmer 30B.
- Живая проба: запрос к `nvidia/nemotron-3-ultra-550b` за 0,45 с вернул
  ответ с `model: nvidia/llama-3.2-11b-vision` — **тихая подмена модели**.
- Бесплатные модели там — хостинг NVIDIA free endpoints, к ним относятся
  trial-условия NVIDIA.
- Вывод: только последний резерв и только с проверкой поля `model` в ответе.

Ссылки: https://blockrun.ai/free, https://blockrun.ai/v1/models
