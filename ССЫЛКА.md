# Ссылка на MeTiger Ai

**https://metiger-ai.pages.dev**

Это единственный адрес продукта. Больше ничего придумывать не нужно: Telegram-бот удалён,
короткое имя `metiger.pages.dev` убрано, собственный домен решено не брать.

## Проверить, что сайт живой

- **https://metiger-ai.pages.dev/api/skills** — должен ответить JSON с числом навыков
  (сейчас 513) и списком категорий (45). Это самый быстрый способ отделить «сайт лежит»
  от «у меня не проходит сеть»: если JSON пришёл, а страница не открылась — дело по пути
  к Cloudflare, а не в проекте.
- `bash scripts/publish.sh --git-only` ничего не выкладывает; полный `bash scripts/publish.sh`
  сам собирает, кладёт на прод и прогоняет дымовые проверки над живым адресом.

## Если не открывается

`ERR_CONNECTION_RESET` / `ERR_CONNECTION_ABORTED` / `ERR_CONNECTION_TIMED_OUT` на `*.pages.dev`
у нашего провайдера уже наблюдались. Тогда по порядку:

1. мобильный интернет (или любой другой выход) — если открылось, виноват путь, а не сайт;
2. WARP или другой туннель — тот же тест, но без смены сети;
3. антивирус с проверкой защищённых соединений и прокси в настройках Windows — их частое
   дело обрывать длинные ответы на середине;
4. если подтвердилось, что режут именно слово `pages.dev` — см. временную ссылку ниже.

## Временная ссылка без `pages.dev`

`*.pages.dev` вырезан реестром целиком (с 09.05.2024), и `*.workers.dev` тоже заблокирован —
зеркало на воркерах помочь не может. Пока адрес один, обход на минуты такой:

```bash
bash scripts/tunnel.sh --keep     # печать: https/<случайно>.trycloudflare.com
```

Скрипт собирает проект при необходимости, поднимает движок (8788) и собранный сайт (4173),
сам скачивает `cloudflared` в `bin/` (в git он не лежит) и **не показывает ссылку, пока не
получит от неё 200**. Что это за адрес: живёт, пока запущен процесс, при каждом запуске новый,
и двигает он локальную сборку этого репозитория — не выложенный прод. Для постоянного адреса
нужен домен, приклеенный к Pages-проекту; eu.org, вопреки более раннему совету, закрыт для
новых заявок, а живые бесплатные зоны — `us.kg` и `dpdns.org` через DigitalPlat (бесплатно,
до 3 имён, вход в Cloudflare как в зону, затем `Settings → Custom domains` проекта).

## Живой просмотр без прода

В песочнице агент может поднять приложение локально: `npm run api` (движок на 8788) и
`npm run dev` (vite на 5173, сам проксирует `/api`). Открывается из панели предпросмотра —
напрямую адрес песочницы не отдаётся, он под токеном доступа (`403 · traffic access token`).
Память в этом режиме лежит в файле `.mt-memory`, а не в Cloudflare KV.
